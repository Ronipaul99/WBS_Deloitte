# Northstar UI

A responsive React and TypeScript starter for a project delivery dashboard.

## Getting started

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

Run the responsive browser smoke test with:

```bash
npx playwright install chromium
npm run test:e2e
```

## Project structure

- `src/App.tsx` contains the dashboard layout and interactions.
- `src/data.ts` contains the starter navigation and dashboard data.
- `src/styles.css` contains design tokens, layout, and responsive styles.
